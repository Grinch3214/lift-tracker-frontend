# User Flow 01 - First training

1. Пользователь открывает сайт.
2. Видит кнопку "+" - добавить упражнение.
3. Выбирает доступную группу мышц из списка.
4. Выбирает доступные упражнения из списка.
5. Упражнения добавляются на главную страницу и соответствуют конкретной дате
6. Добавляет подходы к выбранным упражнениям
7. Видит итог тренировки.
8. Тренировка сохранена локально.
