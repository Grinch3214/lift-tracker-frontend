# Roadmap

## ✅ Milestone 0 — Foundation

**Цель**
Подготовить проект к разработке.

**Готово, когда**

- [x] Vision написан
- [x] Product Discovery завершен
- [x] MVP описан
- [x] User Flow готов
- [x] Архитектура выбрана

---

## ✅ Milestone 1

**Цель**
Пользователь впервые открывает LiftTracker и может полностью провести свою первую тренировку.

**Готово, когда**

- [x] Пользователь может начать тренировку
- [x] Можно записать подходы
- [x] Можно устанавливать таймер отдыха между подходов
- [x] Можно завершить тренировку (автоматически будет завершаться)
- [x] Тренировка сохранилась в истории локально

---

## ✅ Milestone 2

**Цель**
Пользователь видит свой предыдущий прогресс.

**Готово, когда**

- [x] Есть список тренировок
- [x] Можно открыть тренировку

---

## 🚧 Milestone 3 - Workout Customization

**Цель**
Приложением удобно пользоваться на каждой тренировке.

**Готово, когда**

- [x] Можно создавать свои упражнения
- [x] Можно редактировать тренировку
- [ ] Интерфейс работает быстро и удобно на мобильном устройстве (открыто до проверки на реальном устройстве)

---

## ⏳ Milestone 4 — MVP Release

**Цель**
Приложение готово к ежедневному использованию

**Готово, когда**

- [ ] Можно пользоваться приложением без критичных проблем
- [ ] Проведено минимум 10 тренировок
- [ ] Появился список улучшений для следующей версии
