# MVP

## Пользователь может

- начать тренировку без регистрации (выбрать дату — она и есть тренировка, отдельного создания/завершения нет)
- добавить упражнения
- записать подходы
- посмотреть историю
- посмотреть историю упражнения

---

## Пользователь НЕ может

- общаться
- покупать подписку
- использовать AI
- получать достижения
- использовать готовые программы тренировок
- пользоваться социальными функциями
- регистрироваться и сохранять прогресс в облаке
